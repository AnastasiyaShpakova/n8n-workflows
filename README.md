## 🤖 AI-помощник для салона красоты

**Что делает:** отвечает на вопросы клиентов по базе знаний, база обновляется автоматически.

**Как работает:**
1. База знаний загружается из файла на Яндекс.Диске.
2. Текст нарезается на чанки, создаются эмбеддинги через Ollama.
3. Эмбеддинги сохраняются в Qdrant.
4. При вопросе клиента — поиск релевантных фрагментов в Qdrant.
5. Генерация ответа через GigaChat.
6. Отправка ответа в Telegram.

**Стек:** n8n · Ollama · Qdrant · GigaChat · Telegram Bot API · Яндекс.Диск
